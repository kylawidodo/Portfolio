# Kyla Widodo — Portfolio

A single scrollable page: `index.html`, no build step, no dependencies. Open it directly in a browser to preview, or see below to publish it live.

## Structure

- `index.html` — the entire site (markup, styles, and script are all in this one file, by design — makes it trivial to host anywhere)
- `assets/` — optional video (see `assets/README.md`)

## Publishing it live

See the walkthrough in-conversation for exact, no-code steps using GitHub Pages. Short version: merge this branch to `main`, then in the repo go to **Settings → Pages**, set the source to the `main` branch, and GitHub gives you a live URL in a minute or two.
