# Assets

This folder is where optional media for the site lives. The site works fine without anything in here — these are purely upgrades.

- **`reel.mp4`** — a short looping video (10–30s, no audio needed since it autoplays muted) shown near the top of the page, under the hero. Drop a file with this exact name here and it activates automatically. Until then, a subtle textured panel shows in its place.
- **`reel-poster.jpg`** — a still frame shown for a split second while `reel.mp4` loads. Optional.

Tips for the video:
- Keep the file small (under ~15MB) so the page loads fast — export at 1080p, moderate bitrate.
- Landscape orientation, since it fills a wide horizontal panel.
- It plays muted and on loop automatically, so avoid footage with important audio.
